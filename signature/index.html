Nouvel Outlook et Outlook sur le web

  1. Paramètres (roue dentée) → Comptes → Signatures.
  2. Nouvelle signature, nommez-la « Foncier Stratégie », collez (Ctrl + V), enregistrez.
  3. Choisissez-la par défaut pour les nouveaux messages et les réponses de contact@foncierstrategie.fr.

Webmail IONOS

  1. Paramètres → E-mail → Signature.
  2. Collez (Ctrl + V) dans l'éditeur, enregistrez.
